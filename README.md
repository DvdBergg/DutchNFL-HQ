# DutchNFL HQ

The DutchNFL fantasy league dashboard: team news, transfers, waivers, and the League page (standings, prize race, Beat the Median, Guillotine).

- `index.html` is the whole page; `snap.js` makes the "Save as image" posters.
- `data/*.json` holds the numbers. Claude's scheduled refreshes update these files; the page reads them on every visit.
- Hosted with GitHub Pages from the `main` branch. Please keep the link inside the league.
